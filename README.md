# 📝 AI Content Repurposer

An AI-powered tool that transforms long-form content into multiple social-media-ready posts.

## ✨ Features

- Convert blog/content into social media posts
- Supports TXT and Markdown files
- AI-powered content generation
- Multiple post variations
- Simple Streamlit interface
- Local AI processing with Ollama

## 🛠️ Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3.2

## ⚙️ Run Locally

```bash
git clone https://github.com/NancySihag/ai_content_repurposer_pro.git
cd ai_content_repurposer_pro
pip install -r requirements.txt
streamlit run content_app.py
